# Kênh Telegram / Discord hai chiều — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Người ngoài nhắn bot Telegram hoặc Discord → agent của project trả lời ngay trong kênh đó; có bộ lọc phạm vi trả lời (model nhanh) và giới hạn quyền; mọi lượt là job để thống kê.

## Quyết định (rulings)
- **Telegram**: long polling `getUpdates` (không cần URL công khai, hợp với office chạy trên máy). Nhóm: chỉ trả lời khi được tag `@bot` hoặc reply tin của bot; chat riêng: luôn.
- **Discord**: Gateway (websocket) — client websocket tối giản tự viết trong `internal/channels/ws.go` (RFC 6455: bắt tay, frame text/ping/pong/close, mask phía client), không thêm dependency. Intents GUILD_MESSAGES | DIRECT_MESSAGES | MESSAGE_CONTENT. Chỉ trả lời DM hoặc khi bot được tag. Trả lời qua REST `POST /channels/:id/messages`.
- **Cấu hình kênh** (bảng `channels`, migration 00034): project, loại, tên, token (mã hóa bằng secrets box), agent, bật/tắt, `mode` (mức quyền tối đa của lượt chạy, mặc định `read`), danh sách được phép (chat/user id; `*` = ai cũng được; trống = không ai, bật kênh cần ít nhất một dòng), phạm vi trả lời (mô tả chủ đề) + bật lọc, câu từ chối. Mỗi cuộc chat ngoài ↔ một conversation (bảng `channel_threads`).
- **Bộ lọc phạm vi**: khi bật, trước mỗi tin gọi `Engine.Invoke` với model *nhanh*: "Tin này có thuộc phạm vi … không? Chỉ trả lời YES hoặc NO". NO → gửi câu từ chối, ghi job `skipped` mã `out_of_scope` (thống kê được), không gọi agent chính.
- **Lượt trả lời**: tạo job `chat_turn` origin `channel`, trigger `telegram|discord`; `Engine.Send` trong conversation của thread (Mode = mode của kênh) → đợi tin cuối → gửi lại (cắt 4096 ký tự Telegram / 2000 Discord). Trong lúc chạy gửi "đang gõ" (Telegram `sendChatAction`, Discord typing).
- **Chạy nền**: `channels.Manager` khởi động các kênh bật khi office chạy, khởi động lại kênh khi cấu hình đổi, lưu trạng thái (`last_error`, `last_message_at`, bot username).
- **API/UI**: `GET/POST /api/projects/:id/channels`, `PATCH/DELETE /api/channels/:id` (admin; token chỉ ghi, không đọc lại); mục **Kênh** trong project (sidebar), form tạo/sửa, trạng thái kết nối, hướng dẫn tạo bot.

## Tasks
1. Migration + storage (`channels`, `channel_threads`) + test repo.
2. `ws.go` client + test với server websocket tối giản trong test.
3. Telegram adapter (poll, parse, send) + test với server Telegram giả.
4. Discord adapter (gateway hello/identify/heartbeat/MESSAGE_CREATE, send) + test với gateway giả.
5. Manager (allowlist, filter, thread↔conversation, job, reply) + test với adapter giả và `claude` giả.
6. API + UI + ADR-048.
